EnclavAcadam

Hugo Amenouche, Camille Martinet et Juliette Ogier, touls étudianls à l’isdaT, dessinent l’Enclava grâce à une exploration d’ouvrages anciens ayant pour but d’exhumer des modèles d’écritures historiques et de les réactiver pour créer de nouveaux caractères typographiques. En avril 2022, Hugo entreprend de Qunifier l’Enclava dans une version utilisant l'Acadam pendant le workshop « Qunilicious » mené par Bye Bye Binary à l’erg. 

Hugo Amenouche, Camille Martinet and Juliette Ogier, all students at IsdaT, designed the Enclava through an exploration of ancient works with the aim of exhuming historical writing models and reactivating them to create new typographic characters. In April 2022, Hugo set out to Qunify the Enclava in a version using the Acadam during the “Qunilicious” workshop led by Bye Bye Binary at the erg.
